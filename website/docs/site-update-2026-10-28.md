## 소개서 PDF

- HTML: `/ko/brochure`, 파일: `public/downloads/trina-ax-introduction-ko.pdf`.
- A4 5쪽, 한국어 텍스트 선택 가능, 태그 포함, 외부 글꼴 요청 없음. 홈페이지와 같은 제품 → 권한 → 직무 → 도입 → 비용·문의 이야기예요.
- 다크 모드를 저장한 상태에서도 인쇄할 때는 밝은 색상을 사용해요. 본문이 쪽 번호 영역을 침범하지 않는지 검사했고, 5쪽을 이미지로 검수했어요.

```sh
cd website
bun install
bunx playwright install chromium  # 최초 한 번
bun run brochure
```

`scripts/build-brochure.mjs`가 빌드된 HTML과 로컬 자산으로 재생성해요. 실제 서버를 열지 않고 모든 요청을 로컬 파일로 처리해요. 가격·환율·소개서 문구를 바꾸면 다시 실행해요.

이 Mac의 샌드박스에서는 CLI Chromium 실행이 차단되어, 이번 파일은 연결된 Playwright MCP에서 같은 HTML을 인쇄했어요. README에 대체 명령을 남겼어요. 따라서 이 환경에서 `bun run brochure` 전체 실행 성공을 주장하지 않아요.
