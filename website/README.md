# ax.trina.app: the Trina AX website

Static Astro 7 site (no UI framework, self-hosted fonts, no third-party scripts, no analytics), English at `/` and Korean at
`/ko/`. Deployed as Cloudflare Workers Assets. Licensed Apache-2.0 like the rest of the repository.

```sh
cd website
bun install
bun run dev        # http://localhost:4321
bun run build      # -> dist/
bun run preview    # serves dist/ like Workers Assets does, with the headers from public/_headers (http://localhost:4322)
bun run test       # builds, then bun test (SEO, hreflang, JSON-LD = visible FAQ, CSP rules, plan prices, legal pages, "no YC / stars / Drive")
bun run verify     # real browser: console errors, CSP violations, overflow at 360/768/1280, light + dark, links, theme, menu, copy
bun run og         # re-renders public/og.png and public/og-ko.png (needs Google Chrome; icons need `brew install librsvg`)
```

`bun run verify` needs Playwright, which is not a dependency of the site: `PLAYWRIGHT_PATH=/path/to/node_modules/playwright bun run verify`.

## Where things are

| | |
|---|---|
| `src/content/en.ts`, `ko.ts` | all copy, one object per language, same shape (`ko.ts` is `satisfies Copy`). Words are the launch copy deck's (A0-A17). Korean follows `~/.claude/skills/korean-landing-copy`: noun-form titles, 해요체 body, no English eyebrows |
| `src/components/` | one component per section (`Hero`, `WorksWith`, `Problem`, `Features`, `Steps`, `Paying`, `SecuritySection`, `OpenSource`, `Pricing`, `Examples`, `Service`, `Faq`, `FinalCta`), assembled in `Landing.astro`; `SecurityPage.astro` is /security; `LegalPage.astro` is /terms, /privacy and /refund (English only, text in `src/legal/*.en.md`) |
| `src/pages/` | `index.astro`, `ko/index.astro`, `security.astro`, `ko/security.astro`, `404.astro`, `sitemap.xml.ts`, `llms.txt.ts` |
| `src/site.ts` | links (GitHub, install guide), the hosting plans and prices (`PLANS`, the only money figures on the site), the payment resellers, the legal pages, the "book a call" mailto, routes and canonical paths |
| `src/seo.ts` | sitemap with hreflang, JSON-LD (Organization, WebSite, SoftwareApplication, SoftwareSourceCode, FAQPage; no offers), `llms.txt`. All built from the copy |
| `src/styles/` | `tokens.css` is generated by `scripts/gen-tokens.py` (Trina brand tokens; dark values exist three times and `test/tokens.test.ts` keeps them equal); `fonts*.css`, `base.css`, `sections.css`, `stage.css` (the product mock), `secpage.css` |
| `public/` | `_headers` (CSP: self only), `robots.txt`, `theme.js` (applies the saved theme before paint), icons, social cards |
| `wrangler.toml` | `name = "trina-ax-site"`, assets from `./dist`, `not_found_handling = "404-page"` |

## Deploy (the lead does this)

```sh
cd website && bun install --frozen-lockfile && bun run build && bunx wrangler deploy
```

`build.format` is `preserve`, so the build writes `index.html`, `ko/index.html`, `security.html`, `ko/security.html`, `404.html`.
With Workers Assets' default `html_handling` these are served at `/`, `/ko/`, `/security`, `/ko/security`; `/ko` redirects to `/ko/`
and `/security/` to `/security`. Canonical URLs and hreflang use exactly those addresses. After deploying, submit
`https://ax.trina.app/sitemap.xml` in Search Console and Bing Webmaster Tools.

## Before it goes live

- The GitHub repository `potenlab/trina-ax` must be public with the Apache-2.0 `LICENSE`, or every GitHub link, the copy command
  and the SECURITY.md link on the site 404.
- The English install guide is the repository README; the full operator guide (`docs/OPERATOR.md`) is Korean only.

## Fonts

Geist and Geist Mono (OFL, Latin subset) and a Pretendard Variable subset (OFL) for Hangul, all in `src/assets/fonts/` and served from
`/_astro/`. English pages never download Pretendard. The Korean pages load `Pretendard-ko-core.woff2` (about 55 KB), which holds the
syllables the copy uses; `Pretendard-ko-rest.woff2` (about 250 KB, the other common KS X 1001 syllables) is fetched only if a
syllable is not in core. After editing Korean copy run:

```sh
uv run --with 'fonttools[woff]' python -I scripts/build-pretendard.py /path/to/PretendardVariable.woff2
```

`test/fonts.test.ts` fails when a syllable in the copy is missing from core.

## Rules this site keeps

No money figures other than the hosting plan prices from `PLANS` (next to them: renewal, cancellation, refund and the reseller, which Polar and Creem review), no customer names or quotes, no "YC", no star counter, no product other than Trina AX, no
inline scripts or style attributes (the CSP allows none), no external requests at runtime. `test/site.test.ts` checks these.
