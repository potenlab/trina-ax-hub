# ax.trina.app: the Trina AX website

Static Astro 7 site (no UI framework, self-hosted fonts, no third-party scripts, no analytics), English at `/` and Korean at
`/ko/`. Deployed as Cloudflare Workers Assets. This website's own code is Apache-2.0 like the rest of this repository; the
product it describes, [trina-app/trina-ax](https://github.com/trina-app/trina-ax), is AGPL-3.0-only (2026-10-28).

```sh
cd website
bun install
bun run dev --host 127.0.0.1 --port 19592
bun run build      # -> dist/
PORT=19592 bun run preview  # dist/ with public/_headers enforced
bun run test       # builds, then bun test (SEO, hreflang, JSON-LD = visible FAQ, CSP rules, plan prices, legal pages, "no YC / stars / Drive",
                   # AGPL + trina-app repo only, the demo's text is in the HTML, 18 team examples include skills, sources and previews)
bun run verify     # real browser: console errors, CSP violations, overflow at 360/768/1280, light + dark, links, theme, menu, copy,
                   # the demo plays / pauses / replays and stays still under reduced motion, team jump links and motion controls work
bun run og         # re-renders public/og.png, public/og-ko.png and each blog post's card (needs Google Chrome; icons need `brew install librsvg`)
bun run og --blog  # only the blog post cards, public/blog/<slug>.png
```

`bun run verify` uses the pinned Playwright dev dependency (`bunx playwright install chromium` once). It starts its own preview on port 19592, so run it with that port free. `PLAYWRIGHT_PATH` can override the package path.

## Deploy (the lead does this)

```sh
cd website && bun install --frozen-lockfile && bun run build && bunx wrangler deploy
```

`build.format` is `preserve`, so the build writes `index.html`, `ko/index.html`, `security.html`, `ko/security.html`,
`guide.html`, `guide/first-week.html` (and their `ko/` twins), `blog.html`, `blog/<slug>.html`, `404.html`. With Workers Assets' default `html_handling` these are
served at `/`, `/ko/`, `/security`, `/ko/security`, `/guide`, `/guide/first-week`, ...; `/ko` redirects to `/ko/` and `/security/` to
`/security`. Canonical URLs and hreflang use exactly those addresses. After deploying, submit
`https://ax.trina.app/sitemap.xml` in Search Console and Bing Webmaster Tools.

## Before it goes live

- Every GitHub link points into `trina-app/trina-ax` (public, AGPL-3.0-only): the repository, `docs/INSTALL.md` (English install
  guide), `README.ko.md#실행하기` (the Korean list of install guides), `docs/PERMISSIONS.md` and `server/src/policy`. If files move
  there, update `LINKS` in `src/site.ts`. That repository has no SECURITY.md yet, so /security gives the email address only.
- Every "도입 문의" button is still a `mailto:`. Inquiries and quote requests stay on email, with the address visible. The ungated Korean brochure and dated KRW reference prices are implemented; USD remains the actual price.

## Fonts

Geist and Geist Mono (OFL, Latin subset) and a Pretendard Variable subset (OFL) for Hangul, all in `src/assets/fonts/` and served from
`/_astro/`. English pages never download Pretendard. The Korean pages load `Pretendard-ko-core.woff2` (about 75 KB), which holds the
syllables the copy uses; `Pretendard-ko-rest.woff2` (about 239 KB, the other common KS X 1001 syllables) is fetched only if a
syllable is not in core. After editing Korean copy run:

```sh
uv run --with 'fonttools[woff]' python -I scripts/build-pretendard.py /path/to/PretendardVariable.woff2
```

`test/fonts.test.ts` fails when a syllable in the copy is missing from core.

## Rules this site keeps

No money figures other than the hosting plan prices from `PLANS` and their rounded reference values from `KRW_REFERENCE` (next to them: renewal, cancellation, refund and the reseller, which Polar and Creem review), no customer names or quotes, no "YC", no star counter, no product other than Trina AX, no
inline scripts or style attributes (the CSP allows none), no external requests at runtime. `test/site.test.ts` checks these.

## 소개서와 원화 참고가

- 가격·환율은 `src/site.ts`의 `PLANS`, `KRW_REFERENCE`에서만 바꿔요. 원화는 천 원 단위로 반올림한 참고가이고, 실제 결제 가격은 USD예요. 환율을 바꾸면 소개서도 다시 만들어요.
- 소개서 HTML: `/ko/brochure`. 공개 PDF: `/downloads/trina-ax-introduction-ko.pdf` (이메일 입력 없음).
- 재생성: `bun install` → 처음 한 번 `bunx playwright install chromium` → `bun run brochure`.
  스크립트는 Astro를 빌드한 뒤 로컬 HTML·글꼴만 읽어 A4 5쪽을 출력해요. 웹 서버를 띄우거나 외부 서비스를 요청하지 않아요. 본문이 쪽 번호와 겹치면 실패해요.
- 확인: `pdfinfo public/downloads/trina-ax-introduction-ko.pdf`로 5쪽인지 확인하고, `pdftoppm -png -scale-to 1200 public/downloads/trina-ax-introduction-ko.pdf <출력경로>/brochure`로 각 쪽을 검수해요.
- macOS 샌드박스에서 Chromium 실행이 막히면 연결된 Playwright MCP 브라우저로 `/ko/brochure`를 열고 `document.fonts.ready` 뒤 print/light 모드에서 `page.pdf({ format: 'A4', printBackground: true, preferCSSPageSize: true, tagged: true, path: '<사이트>/public/downloads/trina-ax-introduction-ko.pdf' })`를 실행할 수 있어요. 이때 사이트 미리보기는 지정된 19592 포트만 사용해요.
