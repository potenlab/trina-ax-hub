# ax.trina.app: the Trina AX website

Static Astro 7 site (no UI framework, self-hosted fonts, no third-party scripts, no analytics), English at `/` and Korean at
`/ko/`. Deployed as Cloudflare Workers Assets. This website's own code is Apache-2.0 like the rest of this repository; the
product it describes, [trina-app/trina-ax](https://github.com/trina-app/trina-ax), is AGPL-3.0-only (2026-10-28).

```sh
cd website
bun install
bun run dev        # http://localhost:4321
bun run build      # -> dist/
bun run preview    # serves dist/ like Workers Assets does, with the headers from public/_headers (http://localhost:4322)
bun run test       # builds, then bun test (SEO, hreflang, JSON-LD = visible FAQ, CSP rules, plan prices, legal pages, "no YC / stars / Drive",
                   # AGPL + trina-app repo only, the demo's text is in the HTML, role tabs follow the ARIA pattern)
bun run verify     # real browser: console errors, CSP violations, overflow at 360/768/1280, light + dark, links, theme, menu, copy,
                   # the demo plays / pauses / replays and stays still under reduced motion, role tabs switch
bun run og         # re-renders public/og.png and public/og-ko.png (needs Google Chrome; icons need `brew install librsvg`)
```

`bun run verify` needs Playwright, which is not a dependency of the site: `PLAYWRIGHT_PATH=/path/to/node_modules/playwright bun run verify`.

## Deploy (the lead does this)

```sh
cd website && bun install --frozen-lockfile && bun run build && bunx wrangler deploy
```

`build.format` is `preserve`, so the build writes `index.html`, `ko/index.html`, `security.html`, `ko/security.html`,
`guide.html`, `guide/first-week.html` (and their `ko/` twins), `404.html`. With Workers Assets' default `html_handling` these are
served at `/`, `/ko/`, `/security`, `/ko/security`, `/guide`, `/guide/first-week`, ...; `/ko` redirects to `/ko/` and `/security/` to
`/security`. Canonical URLs and hreflang use exactly those addresses. After deploying, submit
`https://ax.trina.app/sitemap.xml` in Search Console and Bing Webmaster Tools.

## Before it goes live

- Every GitHub link points into `trina-app/trina-ax` (public, AGPL-3.0-only): the repository, `docs/INSTALL.md` (English install
  guide), `README.ko.md#실행하기` (the Korean list of install guides), `docs/PERMISSIONS.md` and `server/src/policy`. If files move
  there, update `LINKS` in `src/site.ts`. That repository has no SECURITY.md yet, so /security gives the email address only.
- Every "도입 문의" button is still a `mailto:`. A real inquiry form, a 소개서 PDF and KRW prices are open decisions (PLAN.md).

## Fonts

Geist and Geist Mono (OFL, Latin subset) and a Pretendard Variable subset (OFL) for Hangul, all in `src/assets/fonts/` and served from
`/_astro/`. English pages never download Pretendard. The Korean pages load `Pretendard-ko-core.woff2` (about 55 KB), which holds the
syllables the copy uses; `Pretendard-ko-rest.woff2` (about 250 KB, the other common KS X 1001 syllables) is fetched only if a
syllable is not in core. After editing Korean copy run:

```sh
uv run --with 'fonttools[woff]' python -I scripts/build-pretendard.py /path/to/PretendardVariable.woff2
```

`test/fonts.test.ts` fails when a syllable in the copy is missing from core.

## Rules this site keeps

No money figures other than the hosting plan prices from `PLANS` (next to them: renewal, cancellation, refund and the reseller, which Polar and Creem review), no customer names or quotes, no "YC", no star counter, no product other than Trina AX, no
inline scripts or style attributes (the CSP allows none), no external requests at runtime. `test/site.test.ts` checks these.
